AuraReader 从一块墨水屏开始，重新思考一台随身阅读器真正需要留下什么。

它没有彩色通知、信息流与即时同步。翻页时，设备只做一件事：安静、清晰地呈现文字。书籍留在本地，进度留在设备，常用操作一步抵达。

重要提示

不要把单独的应用固件写入 0x0。

完整刷写需要四个分区。错误写入可能覆盖启动程序与分区信息；墨水屏仍保留旧画面，并不代表设备仍在运行。

先确认数据安全，
再处理问题。

网页刷机支持哪些浏览器？＋

支持具备 Web Serial 能力的桌面版 Chrome 与 Edge。Safari、Firefox 与移动浏览器暂不支持，可改用命令行方案。

刷写会清空 TF 卡里的书吗？＋

不会。刷写发生在设备内部闪存，不会改写 TF 卡。操作前仍建议安全弹出并暂时取出 TF 卡。

设备没有 BOOT 或 RESET 按键怎么办？＋

小纸 Pico 使用 USB Serial/JTAG 自动复位进入下载模式。请使用可靠的数据线并关闭占用串口的软件。

页面停在旧画面，是不是刷写成功了？＋

不一定。电子墨水屏断电后仍会保留画面。正式刷机流程会校验写入，并提示重新启动后的验证步骤。

命令行备用方案需要什么？＋

需要桌面 Python、esptool 与 pyserial。正式固件发布时将同时提供完整四分区参数和可复制的命令。
